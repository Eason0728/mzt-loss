## Phase 1 — 能打

### T1　專案骨架與 build.py
- **產出**：`src/index.html`、`src/styles.css`、`src/app.js`（空殼）、`build.py`、根目錄 `index.html`
- **輸入**：無
- **輸出**：`python3 build.py` 產生單一 `index.html`，用瀏覽器打開看得到三個分頁並可切換
- **內容**：三頁的頁籤切換（登記／成本設定／統計）、標題「墨竹亭 光復店 耗損登記表」、手機優先版面
- **驗收**
  - [ ] `python3 build.py` 無錯誤，根目錄 `index.html` 產生成功
  - [ ] 產出的 HTML 內不含任何外部連結（CSS/JS 全內嵌，離線可開）
  - [ ] 手機寬度（375px）下三個頁籤不換行、不橫向捲動
- **約束**：`build.py` 不得超過 60 行；不得手改根目錄 `index.html`

### T2　`calc` 純函式模組 ＋ 單元測試
- **產出**：`src/app.js` 內的 `calc` 區塊、`tests/test_units.py`
- **輸入**：無（純函式）
- **輸出**：`makeRecord()`、`newId()`、`summarize()`、`rank()`、`dateRange()`
- **驗收**
  - [ ] `makeRecord({耗損量:1.5}, {單位成本:120})` → `金額 === 180`
  - [ ] `makeRecord({耗損量:0.3}, {單位成本:33.33})` → `金額 === 10`（四捨五入到分，不出現浮點尾數）
  - [ ] `newId()` 產出符合 `^L-\d{14}-[a-z0-9]{8}$`，連續產 1000 次不重複
  - [ ] `summarize()` 排除 `作廢 === true` 的紀錄
  - [ ] `python3 tests/test_units.py` 全綠，並貼出輸出
- **約束**：本任務是**全專案唯一寫乘法算金額的地方**

### T3　成本設定頁
- **產出**：`src/app.js` 的 `ui-cost`、`store` 模組
- **輸入**：localStorage `mztloss.items`
- **輸出**：品項清單的新增／修改／停用／搜尋
- **欄位**：品名（唯一）、品類（九選一下拉）、單位（文字）、單位成本（數字）
- **驗收**
  - [ ] 新增一筆後重整頁面，資料還在
  - [ ] 品名重複時擋下並提示，不產生兩筆
  - [ ] 停用的品項在清單標示為停用，且**登記頁的提示與下拉都不再出現**（兩條路都擋）
  - [ ] 搜尋框輸入兩個字能即時篩選
- **不做**：批次貼上匯入（Eason 2026-08-01 決定不做）

### T4　登記頁
- **產出**：`src/app.js` 的 `ui-log`
- **輸入**：成本表、使用者輸入
- **輸出**：一筆耗損紀錄寫入 localStorage `mztloss.loss`
- **流程**：選品名 → 打耗損量 → 選原因 → 送出（三個動作）
- **驗收**
  - [ ] 選了品名後，品類／單位／單位成本三欄自動帶入，且單位與單位成本**不可編輯**
  - [ ] 金額在畫面上即時顯示，數字與 `makeRecord()` 一致
  - [ ] 原因選「其他」時才出現說明欄，且必填
  - [ ] 日期預設今天，可改成昨天（補登）
  - [ ] 送出後表單清空、游標回到品名，可以馬上打下一筆
- **約束**：登記頁不得出現任何「單價」可編輯的入口

### T5　品項記憶（打字提示）與新品項補建
- **產出**：`src/app.js` 的 autocomplete
- **輸入**：成本表（排除停用）
- **輸出**：提示清單；選中則回填四欄
- **驗收**
  - [ ] 打「雞」出現所有含「雞」的品項，選中後四欄回填
  - [ ] 打一個不存在的品名 → 出現「新增這個品項」，填品類／單位／單價後存入成本表，並繼續完成這筆登記
  - [ ] 停用的品項不出現在提示（與 T3 同一條規則的另一條路）

### T6　今日紀錄清單與作廢
- **產出**：登記頁下半部的「今天這幾筆」
- **驗收**
  - [ ] 顯示今日已登記的每一筆（品名、耗損量＋單位、金額、原因）與今日合計金額
  - [ ] 按作廢後該筆變灰、今日合計立刻扣掉
  - [ ] 作廢**不刪列、不改原始數字**，只把 `作廢` 設為 `TRUE`
